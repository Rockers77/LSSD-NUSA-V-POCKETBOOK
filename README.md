# LOS SANTOS COUNTY SHERIFF'S DEPARTMENT
## Operational Pocketbook & Procedural Reference Guide (2026 Edition)

Selamat datang di **LSSD Operational Pocketbook**[cite: 1, 19]. Panduan digital ini mengintegrasikan standar komunikasi radio dan prosedur operasional lapangan bagi seluruh personel Los Santos County Sheriff's Department[cite: 1, 4, 19, 20].

> **PERINGATAN KEPATUHAN:** Seluruh personel wajib memahami dan menerapkan ketentuan sesuai dengan pangkat (*rank*) dan penugasan (*assignment*) masing-masing[cite: 17]. Penyalahgunaan callsign, kode, atau wewenang akan ditindak melalui prosedur disiplin departemen[cite: 17, 31].

### Navigasi Cepat (Sinkronisasi Operasional)
* **Persiapan Shift (Roll Call):** Cek kelengkapan unit dan status melalui [Patrol Shift Operations](vol2-patrol.md#2-0606000-patrol-shift-operations)[cite: 31] lalu laporkan status `10-41` (On-Duty) dan `10-8` (Back in Service) menggunakan [Standard 10-Codes](vol1-communication.md#1022-standard-10-code-table)[cite: 12].
* **Merespons Panggilan:** Cocokkan tingkat urgensi panggilan di [Patrol Priority Response](vol2-patrol.md#2-0603025-patrol-priority-response)[cite: 28] dengan kode respons lampu/sirine pada [Response Code System](vol1-communication.md#1031-response-code-system)[cite: 14].
* **Prosedur Penangkapan:** Ikuti standar penangkapan di [Arrest Procedure](vol2-patrol.md#arrest)[cite: 24], laporkan status `10-95` (Suspect in Custody)[cite: 13], dan bacakan hak tersangka sesuai [Miranda Warning](vol1-communication.md#104-miranda-warning)[cite: 15].
